# Data Detective AI

An AI-powered data analytics platform that enables users to upload datasets, perform data cleaning, generate exploratory data analysis (EDA), visualize insights, and interact with AI for intelligent data interpretation.

---

## Features

- Upload CSV datasets
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Interactive Dashboards
- AI-powered Insights
- Report Generation
- Search Datasets
- History Management

---

## Installation

### Clone the repository

```bash
git clone https://github.com/rithii1702/data-detective-ai.git
```

### Navigate to the project

```bash
cd data-detective-ai
```

### Install dependencies

Frontend

```bash
npm install
```

Backend

```bash
cd server
npm install
```

### Configure Environment Variables

Create a `.env` file inside the `server` folder.

```env
GEMINI_API_KEY=YOUR_API_KEY
PORT=5000
```

### Run the Backend

```bash
npm run dev
```

### Run the Frontend

```bash
npm run dev
```
